# Recent Favorites Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `Recent` first tab to `Add food`, persist `isFavorite` on local foods, and support favorite actions across recent/search/barcode/manual flows without changing diary math or import/export semantics beyond the new field.

**Architecture:** Keep the existing Flutter -> Riverpod -> repository -> Drift stack. Persist favorite state directly on `PrivateFoods`, surface it through `FoodResult`, derive `Recent` from `DiaryEntries`, and keep the current `showEditableFoodDialog()` path as the central save/log flow while adding one silent-save favorite path for external search results.

**Tech Stack:** Flutter, `flutter_riverpod`, Drift/SQLite, `mobile_scanner`, `shared_preferences`, existing `FoodRepository`, `FoodLookupService`, and `ExportImportService`.

## Global Constraints

- Add `isFavorite` to `PrivateFoods` as `bool`, required, default `false`.
- No new `FavoriteFoods` table; favorites remain a property of a local product.
- `Recent` is derived only from local foods referenced by `DiaryEntries.privateFoodId`, ordered by `MAX(occurredAt) DESC`, then `name ASC`, then `id DESC`.
- `Recent` must never show products with no diary usage, even if they are favorites.
- Favorite state persists only for local products; external results become favorites only after creating or reusing a local row.
- Favoriting an external search result must not create a diary entry and must not open the edit dialog.
- Favoriting an external result with a matching local barcode must update the existing local row instead of inserting a duplicate.
- Barcode-less external results must not silently deduplicate by name.
- Export/import remains full-replacement JSON and must include `isFavorite`.
- Existing diary totals, meal grouping, day screen behavior, goals, and settings flows must remain unchanged.

  required String name,
  String? barcode,
  required double kcalPer100g,
  required double proteinPer100g,
  required double fatPer100g,
  required double carbsPer100g,
  required FoodSourceType source,
  bool isFavorite = false,
}) {
  return db.into(db.privateFoods).insert(
        PrivateFoodsCompanion.insert(
          name: name,
          barcode: Value(barcode),
          kcalPer100g: kcalPer100g,
          proteinPer100g: proteinPer100g,
          fatPer100g: fatPer100g,
          carbsPer100g: carbsPer100g,
          source: source,
          isFavorite: Value(isFavorite),
          createdAt: DateTime.now(),
        ),
      );
}

Future<void> setFavorite(int id, bool value) {
  return (db.update(db.privateFoods)..where((f) => f.id.equals(id))).write(
    PrivateFoodsCompanion(isFavorite: Value(value)),
  );
}

Future<void> toggleFavorite(int id) async {
  final food = await (db.select(db.privateFoods)..where((f) => f.id.equals(id))).getSingle();
  await setFavorite(id, !food.isFavorite);
}

Future<List<FoodResult>> getRecentFoods({required bool favoritesOnly}) async {
  final whereFavorite = favoritesOnly ? 'WHERE pf.is_favorite = 1' : '';
  final rows = await db.customSelect(
    '''
    SELECT
      pf.id,
      pf.name,
      pf.barcode,
      pf.kcal_per100g,
      pf.protein_per100g,
      pf.fat_per100g,
      pf.carbs_per100g,
      pf.is_favorite
    FROM private_foods pf
    INNER JOIN (
      SELECT private_food_id, MAX(occurred_at) AS last_used_at
      FROM diary_entries
      WHERE private_food_id IS NOT NULL
      GROUP BY private_food_id
    ) recent ON recent.private_food_id = pf.id
    $whereFavorite
    ORDER BY recent.last_used_at DESC, pf.name ASC, pf.id DESC
    ''',
    readsFrom: {db.privateFoods, db.diaryEntries},
  ).get();

  return rows
      .map(
        (row) => FoodResult(
          name: row.read<String>('name'),
          barcode: row.read<String?>('barcode'),
          kcalPer100g: row.read<double>('kcal_per100g'),
          proteinPer100g: row.read<double>('protein_per100g'),
          fatPer100g: row.read<double>('fat_per100g'),
          carbsPer100g: row.read<double>('carbs_per100g'),
          existingPrivateFoodId: row.read<int>('id'),
          isFavorite: row.read<bool>('is_favorite'),
        ),
      )
      .toList();
}

FoodResult _toResult(PrivateFood row) => FoodResult(

  fatPer100g: row.fatPer100g,
  carbsPer100g: row.carbsPer100g,
  existingPrivateFoodId: row.id,
  isFavorite: row.isFavorite,
);

```dart
class FoodLookupService {
  final FoodSource privateSource;
  final FoodSource externalSource;
  FoodLookupService(this.privateSource, this.externalSource);

  Future<List<FoodResult>> search(String query) async {
    final privateResults = await privateSource.searchByName(query);
    final externalResults = await externalSource.searchByName(query);
    return [...privateResults, ...externalResults];
  }

  Future<FoodResult?> lookupBarcode(String barcode) async {
    final privateMatch = await privateSource.lookupBarcode(barcode);
    if (privateMatch != null) return privateMatch;
    return externalSource.lookupBarcode(barcode);
  }
}
```

The point of this task is not new logic; it is to lock in that favorite metadata survives the existing composition path and that later UI tasks can trust `FoodResult.isFavorite`.

class _BarcodeTabState extends ConsumerState<_BarcodeTab> {
  bool _handlingDetection = false;

  @override
  Widget build(BuildContext context) {
    return MobileScanner(
      onDetect: (capture) async {
        if (_handlingDetection) return;
        final barcode = capture.barcodes.firstOrNull?.rawValue;
        if (barcode == null) return;

        _handlingDetection = true;
        try {
          final result = await ref.read(foodLookupServiceProvider).lookupBarcode(barcode);
          if (!context.mounted) return;
          if (result == null) {
            ScaffoldMessenger.of(context).showSnackBar(
              const SnackBar(content: Text('Product not found - enter it manually')),
            );
            return;
          }
          await showEditableFoodDialog(
            context: context,
            ref: ref,
            initial: result,
            barcode: barcode,
          );
        } finally {
          _handlingDetection = false;
        }
      },
    );
  }
}
